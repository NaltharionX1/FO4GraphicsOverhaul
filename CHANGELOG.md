# Changelog

## 1.0.0

First public release.

- NVIDIA DLSS Super Resolution and DLAA, and AMD FSR 3.1, on a private DirectX 12 layer beside the game's
  DirectX 11 renderer.
- DLSS Frame Generation from 2x to 6x, with a dynamic multiplier, and AMD FSR Frame Generation.
- DLSS 5 Neural Rendering filter, up to three passes (requires a runtime that is not distributed with this mod).
- XeGTAO ambient occlusion, bloom and colour grading passes.
- NVIDIA Reflex on the game thread, before input, with a high-resolution frame limiter.
- An optional G-Sync / variable-refresh flicker fix.
- Physics and timing fixes, motion-vector corrections, an in-game menu and an on-screen display.
